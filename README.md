# HotPoint Scraper
A simple Python web scraper that collects product information from the HotPoint Appliances Kenya TVs category.

## What it collects:
-Product name
-Price
-Currency
-Availability
-Product URL

## Tools used:
-Python
-Requests
-BeautifulSoup
-Pandas
-OpenPyXL

## Output:
-The scraped data is saved in-
-hotpoint_products.csv
-hotpoint_products.xlsx
Currently the scraper collects **50 products.**

## Note:
This project was created for learning and data-scraping practice.
